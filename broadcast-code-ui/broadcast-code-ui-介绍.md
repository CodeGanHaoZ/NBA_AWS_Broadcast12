# Broadcast Code UI — 赛事转播数据终端风设计范式 Skill

> 把「电视转播间 + 球场战术板 + 数据终端」合成一种界面语言。
> 一句话定义：**近黑底 × 信号橙 × 球场线 × 实时数据感**。

---

## 🧩 1. 这是什么

`broadcast-code-ui` 是一个**前端 UI 设计范式 Skill**，封装了一套完整的深色赛事视觉系统。它源自 CSDN BuilderX「Broadcast Code 12h 黑客松极限赛」（NBA × 亚马逊云科技）的官方海报与官网视觉，经过 Token 化、组件化、规则化提炼而成。

装上它之后，AI（WorkBuddy / Claude Code / Codex 等兼容 Agent）生成赛事类页面时不再自由发挥，而是**严格按这套范式输出**——配色、字体、间距、组件、动效、禁令全部有据可查。

### 🎯 适用场景

| 场景 | 是否适用 | 说明 |
|---|---|---|
| 黑客松 / 赛事落地页 | ✅ 首选 | 本范式的原生场景 |
| 体育数据可视化 / AI 解说 overlay | ✅ 首选 | 骨骼追踪帧、Telestrator 标注为此而生 |
| 路演 Demo / 发布会物料页 | ✅ 合适 | 极限、对抗的情绪张力 |
| 政务 / 金融 / 合规场景 | ❌ 禁用 | 需要严肃浅色体系 |
| SaaS 仪表盘 | ❌ 禁用 | 那是「数据终端风」，不是本范式 |

### ⚡ 触发方式

对 Agent 直接说出触发词即可，无需任何配置：

```
Broadcast Code / 黑客松 UI / 赛事落地页 / NBA 可视化 / 转播终端风 / 信号橙深色范式
```

## 🎨 2. 设计系统核心（Token 层）

### 配色纪律：一黑到底，一橙独大

| Token | 色值 | 用途 |
|---|---|---|
| `--bc-bg` | `#0B0B0C`（oklch 0.16 0.005 260） | 转播间黑 · 页面底色，永远近黑，禁浅色模式 |
| `--bc-surface / -2` | `#131315` / `#1B1B1F` | 卡片 / 嵌套层 / hover 底 |
| `--bc-chalk` | `#F5F2EC` | 粉笔白 · 主文字（对比度 13.5:1，WCAG AAA） |
| `--bc-muted` | `#8E8E96` | 次要文字 / mono 标签 |
| `--bc-signal` | `#F9530C`（oklch 0.65 0.21 40） | **唯一主强调色** · 信号橙 |
| `--bc-navy` | `#12183A` | 视频分析帧专用底 |
| 关键点三色 | 红 / 黄 / 青 | 仅限骨骼追踪数据标注，禁作装饰 |

**面积铁律**：信号橙 ≤ 10% 页面面积，只给 CTA、标注、日期、关键数字；橙之外不允许第二强调色。

### 字体配对：四种声部

| 声部 | 字体 | 角色 |
|---|---|---|
| Display | Anton（浓缩大写） | 英文标题 / 大数字，转播记分牌气质 |
| Body | Noto Sans SC | 中文正文 |
| Mono | JetBrains Mono | 数据标签，`0.14em` 字距大写，如 `GAME DATA / AI STORY` |
| Brush | Ma Shan Zheng | ⚠️ **硬性限域**：仅海报式营销页大标语；手册/工具/规范类页面禁用 |

### 间距 / 圆角 / 动效

- 间距 4px 基准：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`
- 圆角三纪律：卡片 `2-4px` 硬边角、日期 pill `999px`、标注圆 `50%`——其余无圆角
- 动效只用 `opacity` / `transform`，`0.2-0.3s` 完成反馈，全部尊重 `prefers-reduced-motion`

## 🖋️ 3. 十大签名元素（范式的灵魂）

这是把「普通深色页」和「Broadcast Code」区分开的识别码，**每页至少落 4 个**：

| # | 元素 | 语义 |
|---|---|---|
| S-01 | 球场线背景 | 中圈/三分弧以 7% 白透明度铺底，页面天然站在球场上 |
| S-02 | 点阵数据块 | 圆点矩阵模拟投篮热图，命中橙点/普通白点 |
| S-03 | Telestrator 标注 | 橙色圆环 + 十字线圈住画面重点，像解说员现场画圈 |
| S-04 | 虚线选框 Marquee | dashed 橙框 + 四角白色手柄，「被选中」的设计工具语言 |
| S-05 | 日期 Pill | 橙底白字胶囊，转播角标的日期/倒计时 |
| S-06 | 皮革纹理色块 | 信号橙渐变 + 噪点，模拟篮球表皮 |
| S-07 | 斜杠分区标签 | `LIVE SIGNAL / COURT VISION`，斜杠染橙 |
| S-08 | 编号管线 | `01input → 04narrate`，大序号 + mono 小写后缀 |
| S-09 | 大数字统计 | Anton 64-144px 关键数字（120 / TOP 8 / 09/27） |
| S-10 | 骨骼追踪帧 | navy 底 SVG 球员骨架，红=持球/黄=无球/青=防守 |

## 🧱 4. 组件规范（16 个）

`references/components.md` 内含完整规范，每个组件覆盖 **default / hover / active / focus / disabled** 全状态：

- **交互**：按钮三变体（primary / ghost / dashed）、表单输入（聚焦橙框 + 3px 光晕）
- **容器**：卡片（1px 硬描边、无阴影、hover 抬升）、奖项卡（marquee 卡头 + 皮革压条）
- **数据**：记分表格（无竖线、mono 数字列、行 hover）、赛程时间线（当下节点脉冲发光）
- **骨架**：导航（唯一允许毛玻璃的位置）、页脚（皮革纹理收边条）

配套 `assets/broadcast-code.css` 提供开箱即用的 CSS 变量 + 工具类，一行引入即可。

## 🎬 5. 动效实验室（6 组）

快、硬、有目的——循环动效只服务「实时数据」语义：

| 编号 | 动效 | 技术 |
|---|---|---|
| M-01 | 数字滚动 count-up | IntersectionObserver + requestAnimationFrame |
| M-02 | 点阵实时刷新 | SVG circle 阵列按序点亮 |
| M-03 | Telestrator 描圆 | `stroke-dashoffset` 描绘动画 |
| M-04 | 数据跑马灯 | CSS keyframes 匀速滚动 mono 字符带 |
| M-05 | 扫描线 | 帧上方扫描光带，表达「正在计算」 |
| M-06 | 入场 + 脉冲 | 8px 上移淡入 + 标注环呼吸 |

## 🚫 6. 强禁止清单（防 AI 味）

范式把「不要什么」写得和「要什么」一样死：

1. ❌ emoji 当 icon 或装饰元素（图标一律 SVG 线条或 mono 字符）
2. ❌ 紫色 / 蓝紫渐变、浅色主题
3. ❌ 圆角气泡卡片、毛玻璃（导航除外）、柔和阴影
4. ❌ 三列 icon 卡片式功能介绍（用编号管线替代）
5. ❌ 信号橙之外的第二强调色
6. ❌ 奶油底 + 赤陶橙、近黑底 + 酸性绿等 AI 默认审美
7. ❌ 默认 Inter / Roboto / Arial / 系统字体
8. ❌ lorem ipsum 占位文本与无意义 stock 图
9. ❌ 手册 / 工具 / 演示类页面使用书法字体

```

├── SKILL.md                       # 范式核心：Token + 签名元素 + 工作流 + 禁令
├── references/
```

**渐进式加载设计**：日常只占索引约 100 词；触发后才载入 SKILL.md（<500 行）；组件细节按需读取 references——不浪费上下文窗口。

## 🛠️ 8. 安装与使用

### 已安装位置（用户级，全项目可用）

```
~/.workbuddy/skills/broadcast-code-ui/
```

目录放入即安装完成，无注册步骤，索引缓存自动收录，改动实时生效。分发包：`broadcast-code-ui.skill`（zip 格式，可直接分享给其他 Agent 用户，同样兼容 Claude Code / Codex 的 skills 目录约定）。

### 五步工作流（Skill 内置）

1. **确认目标** — 页面唯一目标 + 真实文案
2. **引入 Token** — `broadcast-code.css` + 字体 CDN
3. **铺底组装** — 球场线背景 + kicker，再填组件
4. **落签名** — ≥4 个签名元素，信号橙 ≤10%
5. **过禁令** — 禁令清单 + 对比度 + reduced-motion 自检

## 💡 9. 一句话总结

> 它不是「深色页面模板」，而是一套**有情绪纪律的设计语言**：黑是转播间的黑，橙是记分牌的橙，每一帧动效都在说同一件事——**比赛正在进行，数据正在流入。**
