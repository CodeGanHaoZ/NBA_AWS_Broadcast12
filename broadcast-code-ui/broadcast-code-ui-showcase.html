HARD BANS / 强禁止

B-01禁止 emoji 当 icon 或装饰元素
B-02禁止紫色 / 蓝紫渐变、禁止浅色主题
B-03禁止圆角气泡卡片、毛玻璃、柔和阴影
B-04禁止三列 icon 卡片式功能介绍
B-05禁止信号橙之外的第二强调色
